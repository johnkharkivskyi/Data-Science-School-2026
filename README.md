# Data Science School 2026

Repository containing all practical assignments, notebooks, and final projects completed during **Data Science School 2026**.

The school is a five-day intensive program focused on the complete Data Science workflow—from data analysis and preprocessing to machine learning, clustering, and model evaluation. :contentReference[oaicite:0]{index=0}

## Repository Structure

```
.
├── Day 1/
├── Day 2/
├── Day 3/
├── Day 4/
├── Day 5/
└── README.md
```

Each day's directory contains notebooks, datasets (when permitted), and supporting materials for the corresponding practical sessions.

## Topics Covered

- Python for Data Science
- NumPy & Pandas
- Exploratory Data Analysis (EDA)
- Data Visualization
- Data Cleaning & Preprocessing
- Feature Engineering
- Supervised Learning
  - Classification
  - Regression
- Model Evaluation
- Unsupervised Learning
  - K-Means Clustering
  - DBSCAN
  - Dimensionality Reduction
- Final Data Science Project

## Technologies

- Python 3
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Learning Outcomes

During the school, participants work through the complete machine learning pipeline:

1. Understanding and exploring datasets
2. Cleaning and preprocessing data
3. Feature engineering
4. Training machine learning models
5. Evaluating model performance
6. Presenting insights and results

## About Data Science School 2026

Data Science School 2026 is an intensive educational program designed for students and early-career professionals interested in Data Science. Participants gain hands-on experience solving real-world problems under the guidance of industry mentors, culminating in a final project presentation. :contentReference[oaicite:1]{index=1}
